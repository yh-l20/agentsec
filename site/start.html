01 / 首次安装

把工作台装在自己的电脑上。

0.4.0a2 安装器已发布，一次准备界令 0.7.0a2、Hermes 和 OpenClaw。按下方步骤安装到新目录；已经装好这一版，可以直接查看工作台使用说明。

Windows 用户：先准备 Ubuntu / WSL

安装器在 Ubuntu 中运行，不会替你安装 WSL。在 PowerShell 中运行下面的命令，按屏幕提示完成系统安装，再打开 Ubuntu 24.04。后续命令都在 Ubuntu 终端中运行；已有合适环境可以跳过。

wsl --install -d Ubuntu-24.04
0.4.0a2 安装器 · 预览版已发布

一次安装，准备两种助手。

配套安装器已公开，三个下载文件已与审核版本核对。适用于 Ubuntu 24.04 / WSL Ubuntu 24.04、x86_64 电脑，首次安装需要终端。

安装器准备 Hermes 和 OpenClaw，创建工作时选择一种。新版使用独立目录，已有旧安装和旧工作不会自动升级。

下载 0.4.0a2 安装器 ↓安装器与核验文件 ↗
下载后，按这一步安装 0.7.0a2

把下载的 yuanxingmu-installer-0.4.0a2.pyz 放到 Ubuntu 的主目录（~），然后在 Ubuntu 终端运行：

/usr/bin/python3 -I "$HOME/yuanxingmu-installer-0.4.0a2.pyz" --install-root "$HOME/yuanxingmu-v07a2" --system-deps

Windows / WSL 用户可以先在 Ubuntu 终端运行 cd ~，再运行 explorer.exe .，把下载的文件拖进打开的文件夹。

点击“复制”取得完整命令；手机上也可以左右滑动查看。

--system-deps 允许安装 Ubuntu 提供的隔离程序及所需系统组件，可能要求输入 Ubuntu 密码。程序只为界令设置专用隔离规则；隔离检查失败时，安装会停止。

安装器固定准备界令 0.7.0a2、Hermes 0.21.2 / v2026.9.11、OpenClaw 2026.9.4 和 Node.js 24.16.0。无须分别执行 pip、Git 或 npm；系统依赖已经备齐时，可以省略 --system-deps。

上面的命令安装到 ~/yuanxingmu-v07a2。已有安装不会被覆盖；中断后重新运行同一命令，只会继续它自己尚未完成的安装。无法确认已有目录时会停止，请保留原目录和工作记录。

安装器不提供模型账号。装好以后，仍需要填写自己的模型接口，并选择这份工作能用的资料。

已经装过旧版，怎样保留它？

上面的命令将 0.7.0a2 装到新的 ~/yuanxingmu-v07a2。如果这个目录已被其他版本占用，请把命令中的目录改成另一个空位置，后续也从那个位置启动。

"$HOME/yuanxingmu-v07a2/open-yuanxingmu"

旧资料和聊天保留在旧版中；新版请重新填写模型连接、放入资料并新建工作。先关闭旧版中的工作、退出旧工作台，再打开新版。本版不做原地升级。

旧 0.6 和 0.7.0a1 安装继续从原来的入口打开。0.7.0a2 使用新目录，旧资料、聊天和已有工作保持原来的版本与保护能力；不会自动升级，也不做原地升级。

02 / 打开工作台

打开你的本机工作台。

按上面的新目录安装后，在 Ubuntu 终端运行：

"$HOME/yuanxingmu-v07a2/open-yuanxingmu"

如果安装时改过目录，请使用那个目录下的 open-yuanxingmu。以后仍用同一条命令打开。

以前按手工步骤安装的，怎样打开？

继续使用原来的入口。按本页历史步骤安装在默认目录时，运行：

"$HOME/yuanxingmu/.venv/bin/python" -I -m yuanxingmu desk

程序会尝试打开浏览器。如果没有自动打开，请把终端中完整的 http://127.0.0.1:18910/#access=… 链接复制到这台电脑的浏览器。

使用期间请保留这个终端，管理链接请只供自己使用。工作台重启后会给出新链接，已有工作和权限仍保留。它与稍后进入助手聊天的链接不同。

工作台会在 ~/yuanxingmu-v07a2/workbench 保存资料副本、聊天、密钥和权限记录。请保留这个目录；首次打开前不要手动创建一个空目录。

填写工作名称，例如“整理活动预算”；再在“这份工作要完成什么”里写清目标和限制。练习可以填写：

读取 quote，整理三个费用项目并算出总额，只在聊天中回答。供应商还没确认，不要自行发消息、上传、提交表单或修改文件。

界令会按这里的要求检查是否跑偏。若这次确实要发送或上传，请在目标中写明，再按下一节选择允许接收的对象。

展开“防护设置与技能”，确认五项检查已勾选，处理方式为“拦截或等本人确认”。仅接上模型和放入资料，还不足以确认防护已生效；创建后请再查看这份工作的防护记录。

填写自己的模型连接

  1. 模型地址：服务商提供的完整接口地址，通常以 /v1 结尾。
  2. 模型名称：服务商提供的模型标识，或本机模型服务设置的名称。
  3. 连接密钥：模型服务提供的 API Key。云端服务用 HTTPS；不需要密钥的本机 HTTP 服务可以留空。

模型服务需要支持工具调用和 OpenAI 兼容的 Chat Completions 接口；连接时请使用模型服务提供的 API 地址和密钥。本机地址如 http://127.0.0.1:1234/v1 必须能从当前 Linux / WSL 访问。

默认用同一个模型分别做事和检查。也可以展开“用另一个模型做防护检查”，填写另一个服务；它会收到工作目标、候选操作、技能内容和回答文字。检查也可能误判。

密钥保存在这台电脑的工作目录中，供以后继续使用；页面不把它放进浏览器存储或操作记录。所选模型仍会收到完成聊天所需的内容。

04 / 导入文本

先用一份短文本试一次。

用记事本或文本编辑器把下面内容保存为 UTF-8 的 quote.txt，再在工作台选择这个文件：

项目：春季客户活动（练习资料）
场地：6000 元
物料：2800 元
摄影：1200 元
备注：报价仅供内部讨论，尚未确认供应商。

把它在对话中的资料名称设为 quote。你也可以选自己的 .txt 或 .md 文件。

当前最多 8 份 UTF-8 文本，每份 256 KiB，合计 1 MiB。PDF、Word、Excel 和图片还不能直接导入；模型能否一次读完，另受上下文长度限制。

如果只在聊天里整理资料，保持自动执行关闭，然后点击“创建独立工作”。创建时保存文件副本，后来修改原文件不会自动同步；要换资料，请建立新工作。

需要发送、上传或提交时，先完成下面的范围设置，再创建工作。

05 / 操作范围 · 可选

能发给谁，由你先选好。

这一步用于需要对外做事的工作。第一次可以跳过，先完成上面的报价练习。

  1. 先登记接收位置。打开右侧的“可确认的操作对象”，点击“添加操作对象”，填写名称、代号和操作类型。消息可用普通接口、飞书或 Slack 群聊；上传为文本文件；表单需填写允许的字段名。
  2. 填写正确的接收地址。填写服务或管理员提供的完整 HTTPS API 地址，聊天页面的链接用于浏览器访问。保存对象只记录配置，不会试发内容。
  3. 再选这次能用的对象。回到创建表单的“自动执行范围”，点击“刷新可选对象”，勾选“让 AI 在选定范围内自动完成”，逐个勾选允许接收本次资料的对象。
  4. 核对目标，再创建工作。目标中写清允许公开哪些内容。勾选的对象可以接收本次资料；通过防护检查后，范围内的消息、上传和表单会直接执行。
一次约定范围，之后不必逐项批准。本工作最多 8 次自动提交，每次最多 8 KiB，总计 64 KiB。未选对象、超限操作会转为待核对；其他防护检查也可能拒绝或暂停。发送结果不明确时不会自动重发。

邮件仍需要逐封核对。删除或覆盖已登记的指定文本文件，也要先看文件位置及原文，再明确确认；这些操作不会因为打开自动执行就自行发生。

接收位置和范围在创建时固定。后来修改对象设置，不会悄悄扩大旧工作的权限；要采用新的设置，请建立新工作。

06 / 进入聊天

到原来的聊天界面里，交代工作。

在工作卡片点击“启动工作”。完成后，点击“进入 Hermes”或“进入 OpenClaw”，打开创建时选择的助手。首次启动可能需要几十秒。

聊天链接也包含访问凭证，请只供自己使用。回答来自你选择的模型，操作结果可以在工作台核对。

完成短文本练习时，输入：

请读取 quote，列出三个费用项目，算出总费用，并说明还有什么需要确认。直接在聊天里回复我。

三项费用合计 10,000 元，供应商尚待确认。你应看到资料读取操作和模型回答。然后可以继续说“改成三句话”或“整理成表格”。

需要执行已授权的操作时，在聊天中写明资料和对象代号；范围内通过检查即可自动完成。完成后，在工作台查看操作状态，并到接收服务核对内容。

结束资料使用

确定不用了，再永久收回权限。

如果这项工作不应再读取或发送资料，在卡片中点击“收回权限”，看清提示后，再确认“永久收回权限”。

本版无法恢复收回的权限。后续通过界令读取或发送资料会被拒绝，换会话或重开工作台也不会恢复。这不会清除已经读到的内容、撤回已完成的发送或停止本地计算。

需要一起结束运行时，再点击“暂时关闭”。权限已永久收回的工作不能重新启动。

预览版说明

遇到问题，先看程序的实际状态。

安装器提示隔离检查没通过

确认在 Ubuntu / WSL 内使用系统 Python。允许安装系统依赖时，可使用带 --system-deps 的命令。完成后仍失败，请保留提示并请管理员检查；程序不会跳过隔离继续运行。手工安装可查看 doctor 输出中的 reason。

找不到 open-yuanxingmu 启动入口

这个入口由安装器在完成安装后提供。先确认安装是否成功，以及启动命令是否使用了实际安装目录；以前按手工指南安装的，请使用上方保留的手工启动命令。

工作台打不开，或提示访问凭证失效

确认启动工作台的 Ubuntu 终端仍在运行，再从该终端打开完整管理链接。工作台重启后需要使用新链接。不要把这个管理链接当作助手的聊天入口。

模型连接失败，或没有读取资料

模型报 401、404 或无法调用工具时，核对密钥、接口地址、模型名称及工具调用支持。资料太长时，先用短文本重新建立工作。本版没有编辑已建工作模型配置的表单，需改配置时请建立新工作。

启动失败、端口被占用或服务异常中断

先刷新页面查看实际状态。按本页安装时，每项工作的目录位于 ~/yuanxingmu-v07a2/workbench/profiles/，可查看其中的 supervisor.log 和 gateway.stderr.log；具体排错见下方命令行指南。

如果状态是“运行中断”或“状态待确认”，表示异常退出后的清理还没有确认。保留日志与 lifecycle.json，先检查记录中的进程，不要删除权限库或改状态绕过检查。

更换版本或直接修改实例配置后不能启动

当前实例保留创建时的资料副本与校验记录。请保留安装器准备的 Hermes 0.21.2 / OpenClaw 2026.9.4，不要直接修改生成的配置或替换运行文件。本版暂未提供原地升级与恢复撤销权限的流程。

怎样让 AI 写邮件，由我确认发送？

新版支持先让 AI 起草，再由你核对或修改收件人、主题和全文，最后明确确认发送。在工作台设置自己的发件邮箱，再新建一份工作；旧工作不会自动获得邮件功能。按邮件演示中的四步操作，或查看完整邮件指南 ↗。目前每封只支持一个收件人和纯文本正文，暂不支持附件。消息、上传和表单另按上方“操作范围”设置。

0.7 工作台支持 OpenClaw 2026.9.4 和 Hermes 0.21.2 / v2026.9.11 的原生网页，创建工作时选择。配套 0.4.0a2 安装器准备两套环境；旧安装和旧工作不会自动升级。
