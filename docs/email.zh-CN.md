# 让 AI 起草邮件，由你确认发送

让 AI 根据报价或其他资料拟好邮件，再到元星木工作台核对收件人、主题和全文。每封邮件都需要你明确确认，保存草稿不会发送邮件。

[观看邮件实机演示](https://yh-l20.github.io/agentsec/email-demo.html) · [开始使用](https://yh-l20.github.io/agentsec/start.html)

## 1. 配置发件邮箱，建立一份工作

在带邮件功能的工作台里展开“发件邮箱设置”，填写发件地址、邮箱登录账号，以及邮箱服务商提供的授权码或应用密码。服务器和端口请选择服务商提供的“SMTP SSL/TLS”配置，通常使用 465 端口，以服务商说明为准；本版暂不支持 STARTTLS。然后点击“保存发件邮箱”，保存设置不会发出邮件。

选择模型、放入资料，新建一份工作。**旧工作不会自动获得邮件功能**；请保留原工作，在新版工作台里新建一份工作来使用邮件核对。

授权码会保存在这台电脑上，仅当前系统用户可以访问；当前版本不对这份本机配置额外加密。工作台不把授权码写入浏览器存储，也不交给 AI 的工作环境。请在邮箱设置里填写授权码。

## 2. 让 AI 起草并递交工作台

进入这份工作的 OpenClaw 或 Hermes 对话，告诉 AI 要写什么、发给谁。例如，把下面的“收件人邮箱”换成实际地址：

> 请读取我放入的报价资料，写一封给【收件人邮箱】的报价说明。说明费用和需要对方确认的事项，把完整邮件草稿交到工作台，让我核对后发送。

回到工作台，在对应工作卡片中点击“查看邮件草稿”。**AI 在聊天里回复了邮件内容，不代表草稿已经保存。** 请以工作台里的草稿列表为准。

## 3. 核对全文，按需修改

打开“核对邮件”，看清发件地址、收件地址、主题和完整正文，尤其是金额、日期和需要对方确认的内容。

需要调整时，点击“编辑草稿”。收件人、主题和正文都可以修改。点击“保存修改”后，再核对保存后的完整内容；保存修改本身不会发送。更换发件邮箱后，也需要重新核对。

不想发送这份草稿，可以选择“弃用草稿”。确认弃用后，这份草稿不能再发送。

## 4. 确认发送，再查看实际状态

勾选“我已核对发件人、收件人、主题和全文”，再点击“确认发送这封邮件”。**这次确认只适用于眼前这封邮件。** 之后的新草稿仍需要另行核对和确认。

| 工作台显示 | 表示什么，接下来怎么做 |
| --- | --- |
| 待核对 | 邮件还没有发送，可以核对、编辑或弃用。 |
| 发送中 | 正在提交给邮箱服务，请等待结果。关闭窗口不会取消这次发送。 |
| 已提交邮箱服务 | 邮箱服务已接收邮件，**不代表已经投递到收件箱，也不代表对方已经阅读**。 |
| 结果不明 | 暂时无法确认邮箱服务是否已接收。先核对邮箱中的发送记录；没有记录也不能证明未发送，必要时向收件人或邮箱服务商核实。确认前不要重新起草或发送同一封邮件，程序不会自动重发。 |
| 尚未开始发送 | 这次邮件尚未开始发送。检查并处理邮箱设置问题后，让 AI 重新提交一份新草稿，再核对并确认发送。旧草稿保留处理记录，不能再次发送。 |
| 已弃用 | 这份草稿不能再发送。 |

## AI 暂时关闭后，草稿还在

在工作卡片中点击“暂时关闭”，等工作台确认正常关闭后，仍可查看、编辑和确认待核对的邮件草稿，无须为了处理草稿重新启动 AI。只关浏览器标签页不会停止 AI。

“永久收回权限”会禁止这份工作继续发送待核对的草稿，已有记录仍可查看。它不能撤回已经提交的邮件；如果发送已经开始，也不能把关闭窗口或收回权限当作邮件已被撤回。

## 这一版的范围

每封邮件只支持**一个收件人和纯文本正文**，暂不支持抄送、密送或附件。主题最多 200 个字符，正文最多 64 KB。邮箱服务商需要支持工作台使用的加密发信方式。

演示使用 **OpenClaw 2026.9.4 和本地 Qwen3-4B**，资料是合成报价，邮件交给这台电脑上的加密测试收件服务。该服务不向外转发，演示没有向真实外部邮箱发送邮件，也不提供生产环境防护率的结论。实际使用时，你选择的模型会看到聊天和交给它的资料；使用云端模型时，这些内容会交给相应模型服务商。

开发者需要核对实现与边界时，见[邮件确认的实现说明](REVIEWED-EMAIL.md)。
